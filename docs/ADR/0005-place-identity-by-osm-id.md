# ADR 0005: 地点の同一性を osm_id で判定し、正規化辞書を持たない

- 状態: Accepted (2026-08-23、前身 PoC で 2026-08-16 に検証)
- 文脈タグ: ジオコーディング, 構造化

## 背景
放送は同じ場所を違う表記で呼ぶ。`千葉市中央区` と `中央区`、`とね町` と `利根町`、
`津田沼駅前` と `津田沼駅`。表記で数えると同じ場所が複数地点になる。文字起こしの誤りも
混ざるので、表記の揺れは日本語の問題ですらなく、あらゆる言語で起きる。

## 決定
同一性は `osm_type` と `osm_id` の組で判定する。表記の正規化辞書は**持たない**。

locitorium が表記ゆれを吸収して同じ OSM 実体を返すので、その結果を信じる。本文との
照合には全表記と正規化名の両方を使うが、同一性の判断には使わない。

## 影響
千葉豪雨の地点が 47 から 34 に収斂した。`とね町` が `利根町` に、`津田沼駅前` が
`津田沼駅` に同一視され、しかも誤った表記の側が正しい OSM 実体に寄った。

自前の辞書を持たないので、日本語以外にそのまま広げられる。前身の PoC はコンゴ民主共和国
の仏語放送も扱っており、そちらでは gazetteer によるファジー照合を行っているが、
それは Nominatim の外側で ASR の崩れを補正するためのもので、同一性判定とは別の層である。

## 検討した代替案
- **自前の地名正規化辞書**: 却下。日本語以外に広げられず、保守が増え、そして接地の
  仕事と二重になる
- **表記で数える**: 却下。同じ場所が複数地点になる

## 留意
接地できない地点が一定割合残る。日本語のラジオ素材では約 3 分の 1 で、原因は 2 つある。
文字起こしの誤り(`三宝市`=三原市、`森谷市`=守谷市)と、範囲を持たない表現
(`関東`、`北部`、`沿岸部`)。後者は接地しないのが正しい。この 2 つは対処が違うので、
利用者に区別して報告する必要がある。
