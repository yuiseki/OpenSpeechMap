# ADR 0008: 集計を地理的スコープに閉じる

- 状態: Accepted (2026-08-23、前身 PoC で 2026-08-15 に検証)
- 文脈タグ: 地図, 構造化

## 背景
2026-07-28 の熊本地震を追跡している最中に、2026-08-13 に千葉で豪雨災害が発生した。
同じ放送・同じレンズの出力から 2 つの事象を並行して追跡できるかが問われた。

素朴に作ると、ある時間帯の見出しや警報が「その時間帯に流れた該当報道すべて」から
作られるため、熊本の地図に千葉の見出しが載る。

## 決定
集計を bbox に閉じる。見出し・警報・フェーズの集計を、bbox 内の地点に紐付いた
レコードだけから作る。どのレコードにも紐付かない地点は落とす。他の事象の見出しを
借りないようにするため。

レンズの出力は事象に依存しないので、1 つのキャッシュから複数の地図を作れる。bbox だけを
変えて別の事象を追う。

## 影響
8/13 20時台の同一 54 セグメントから、熊本 bbox は 0 地点、千葉 bbox は 5 地点。
分離できている。

## 検討した代替案
- **事象ごとにレンズの出力を分ける**: 却下。レンズの判定は事象に依存しない。同じ出力から
  複数の地図を作れる方が安い
- **地点のクラスタリングで自動分離する**: 検討に値するが未実装。bbox は人が与える

## 留意
bbox は矩形なので隣接自治体が漏れる。千葉の bbox に江戸川区が入る。行政境界による
絞り込みが本来は正しい。接地結果は OSM の relation を持っているので、原理的には
境界で絞れる。
